Official API.
Author permissions.

This tool uses an approved third-party CurseForge developer key. The key stays in memory for the current launcher session. Requests go directly to validated official API and download hosts; the project runs no proxy service.

Author-disabled downloads stop the installation. The add-on does not guess download URLs to bypass restrictions.

Applying for this tool does not require creating a game in CurseForge for Studios. Use the third-party API application process. Approval is decided by CurseForge.

Build it locally.

Requires the supported Dawn installation and PowerShell. The source repository includes no Dawn binaries or API keys.

Download the source from GitHub, open PowerShell in its folder, and run:

.\build.ps1
.\test.ps1
.\install.ps1

Fully restart Dawn, then open CurseForge → Browse mods and modpacks. The local panel verifies your API key before enabling catalog access.

Disable the add-on with .\uninstall.ps1 and restart Dawn. See the README for requirements and limitations.

What has been checked.

92 API assertions and 43 installer assertions passed using offline fixtures, alongside UI and install-script checks. Dawn's own profile codec accepted the generated profile format.

Live authenticated catalog access, downloads, and full game launches still need validation. The catalog currently shows the first 50 matching projects; automatic updates and individual mod removal are not implemented.
